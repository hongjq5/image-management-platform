# 效果与演示

截图来自 2026-09-19 本地运行的真实 Vue 应用和 Spring Boot 后端。几何图片是专门生成的演示素材，账号为临时测试账号；没有使用真实业务数据。截图中的菜单来自实际页面，是否可执行仍由后端权限检查决定。

## 团队素材管理

![团队图库](images/team-gallery.png)

一个空间集中查看图片，可按名称、分类、标签、时间、尺寸和颜色检索。管理员可进入成员管理和空间分析。

## 在线编辑

![裁剪和协作](images/image-editor.png)

图片通过短期签名从私有 COS 加载。团队场景先取得编辑权，再旋转、缩放和裁剪；确认后上传结果替换原图。

## 成员权限

![成员角色](images/team-members.png)

管理员、编辑者和浏览者对应不同操作权限。后端读取真实成员关系进行检查，不相信客户端传来的角色。

## 三分钟本地演示顺序

1. 按 [快速启动](quickstart.md) 运行服务，注册两个自己的测试账号。
2. 主账号创建团队空间，上传几张无敏感信息的图片，编辑名称、分类和标签。
3. 添加另一个账号为浏览者，验证可查看但无法上传 / 编辑；改为编辑者后再次验证。
4. 打开一张图片的编辑页面，进入编辑、旋转或缩放后保存，观察图片数不增加。
5. 展示空间分析，再指出元数据存在 MySQL、图片存在 COS、Redis 保存会话。

双连接协作已用原生 WebSocket 客户端验证；真实浏览器双标签页协同交互仍是后续验收项，不将单页截图当作双端同步的证据。

## 是否需要服务器

本地演示、面试讲解和 GitHub 源码托管都不需要额外购买服务器。需要让面试官通过公网地址体验时，再考虑 Linux 云主机、HTTPS、域名、数据库备份和监控；宝塔是管理面板，不是服务器本身，也不是项目必需依赖。

代码仓库的可见性不会自动保护公开 Demo。公网演示应另建隔离的演示库和桶，限制上传、清理演示数据、做好登录限流；不要暴露自己的私人图库。当前没有公网 Demo 链接。
