## COS 私有访问与跨域配置

经用户明确批准，桶 ACL 已从 `public-read` 改为 `private`，新增本地开发 CORS 规则：来源为 `http://localhost:5173`、`http://127.0.0.1:5173`；方法 GET/HEAD；允许请求头 `*`；暴露响应头 ETag、Content-Length；预检缓存 600 秒。已通过 SDK 重新读取并逐项核对。

只读检查确认没有桶策略，原有唯一对象 ACL 为 `default`，继承桶权限；该对象匿名 GET/HEAD 均返回 403，分别签名的 GET/HEAD 均返回 200。两个允许来源的实际请求及 OPTIONS 预检通过，未授权来源没有获得 `Access-Control-Allow-Origin`。原有对象内容没有修改或删除。新增上传对象另由云模式冒烟验证匿名拒绝与签名访问。

CORS 控制浏览器读取跨域响应，不代替业务鉴权；签名 URL 在有效期内仍是持有者访问凭证。未来新增对象 ACL、桶策略或部署域名时，需要重新验证。

脚本默认只使用 Node 内置模块。云模式用 ImageIO 生成的 32×32 RGB PNG；早期微型透明 PNG 被 COS 拒绝后已替换为有效测试图片，最终完整云模式通过。部署后可通过 `SMOKE_CORS_ORIGINS` 指定逗号分隔的实际前端来源。脚本不打印密码、Cookie 或签名 URL，清理仅针对本轮创建的资源；演示账号只存在于专用测试库。
