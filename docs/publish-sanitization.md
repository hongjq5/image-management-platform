## 配置使用

本仓库只提供源码，不包含可用云账号、密钥、桶或完整运行环境。使用者需自行注册腾讯云账号、创建 COS 桶并按需开通数据万象，再补充自己的配置并调试。

后端将 `yu-picture-backend/application-local.example.yml` 复制为同目录的 `application-local.yml`，填写自己的 MySQL、Redis 和 COS 配置。该文件应保持被 Git 忽略，也不要放入 `src/main/resources` 或打包产物。

也可通过环境变量提供 `DB_PASSWORD`、`REDIS_PASSWORD`、`COS_SECRET_ID`、`COS_SECRET_KEY` 等值。云凭据只能由后端读取，不得放入前端 `VITE_` 变量。

登录账号通过应用注册创建，数据库结构文件只负责建表。不要把注册结果、Cookie、真实用户数据或备份加入仓库。
